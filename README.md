# Фабрика

Браузерная 2D игра про строительство завода. Добывай руду, прокладывай конвейеры, налаживай производственные цепочки и защищай Ядро от жуков.

## Как запустить

Хостинг и сервер не нужны. Скачай репозиторий и открой `index.html` двойным кликом в любом современном браузере (Chrome, Firefox, Edge, Safari).

Прогресс прохождения сохраняется в браузере (localStorage).

## Уровни

| № | Название | Цель | Что открывается |
|---|----------|------|-----------------|
| 1 | Первые шаги | 40 железной руды | Конвейер, бур. Врагов нет |
| 2 | Плавка | 30 железных пластин | Плавильня, разветвитель, турель, стена |
| 3 | Медь | 30 шестерён и 40 проводов | Сборщик, хранилище, патроны |
| 4 | Электроника | 25 микросхем | Сталь, стальная стена |
| 5 | Сердце машины | 15 моторов и убить Матку | Мотор |

## Производственные цепочки

- Плавильня: железная руда → железная пластина, медная руда → медная пластина, 2 камня → кирпич, 2 железные пластины + уголь → сталь.
- Сборщик: 2 железные пластины → шестерня, медная пластина → 2 провода, железная пластина + уголь → 3 патрона, 3 провода + железная пластина → микросхема, 2 шестерни + микросхема + сталь → мотор.

Здания отдают продукцию в соседние конвейеры (кроме тех, что направлены в само здание) и в соседние здания, которым она нужна. Плавильню и сборщик можно ставить вплотную друг к другу или к Ядру.

## Враги

- Жук: обычный.
- Бегун: быстрый и хрупкий.
- Танк: медленный, с бронёй. Против него нужны патроны.
- Матка: босс последнего уровня, порождает жуков.

Ядро отстреливается встроенной пушкой. Турели заряжаются железными пластинами или патронами через конвейер.

## Управление

| Клавиша | Действие |
|---------|----------|
| ЛКМ | построить / выбрать здание / двигать карту |
| ЛКМ + тянуть | проложить конвейер |
| ПКМ | снести (возврат 75% ресурсов) |
| 1…9 | выбрать постройку |
| R | повернуть (без выбранной постройки поворачивает ленту под курсором) |
| X | режим сноса |
| WASD / стрелки | двигать камеру |
| колесо мыши, + / - | масштаб |
| Пробел | пауза |
| Esc | отмена / меню паузы |

## Структура кода

- `index.html` - разметка экранов и интерфейса.
- `css/style.css` - оформление.
- `js/data.js` - предметы, рецепты, здания, враги, уровни. Баланс меняется здесь.
- `js/world.js` - состояние уровня, генерация карты, волны, поиск пути врагов.
- `js/buildings.js` - логика зданий и перемещения предметов.
- `js/enemies.js` - враги и снаряды.
- `js/render.js` - отрисовка на Canvas.
- `js/ui.js` - панели интерфейса.
- `js/main.js` - управление, игровой цикл, сохранение прогресса.
